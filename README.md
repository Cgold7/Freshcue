# 🥑 Freshcue Pantry First

A lightweight, zero-friction freshness tracker designed to eliminate kitchen waste before food spoils. 

Unlike bloated inventory apps that require scanning every spice jar in your cabinet, **Freshcue** focuses purely on perishable urgency: log what you bought, tap an expiration window, and let the freshness countdown handle the rest.

---

## ✨ Features (Core Module)

* **Rapid Add Bar:** Add items in seconds with preset expiration chips (`+2d`, `+5d`, `+10d`, `+30d`)—no manual date pickers required.
* **Freshness Countdown:** Items automatically sort by urgency with real-time color indicators:
  * 🔴 **Critical:** $\le$ 24 hours or expired
  * 🟡 **Approaching:** 2 to 3 days remaining
  * 🟢 **Fresh:** 4+ days remaining
* **One-Tap Actions:** Quickly mark items as **Used** (consumed) or **Tossed** (wasted) with single-touch controls.
* **Offline-First & Local:** Zero account setup or backend sync required; data persists cleanly in local browser storage.
* **Mobile-First Interface:** Optimized for quick one-handed use on mobile viewports.
